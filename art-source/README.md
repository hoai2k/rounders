# Source art (reference)

The files exactly as delivered, before intake: originals that still have their
solid backdrop, oversized renders, alternate takes. `npm run intake` moves
everything it processes in here.

Nothing in this folder is loaded by the game — it exists so a cutout can be
redone later with different settings, or a canonical render consulted when new
parts are needed.

- `characters/` — delivered character art (canonical images and split parts)
