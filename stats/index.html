Blank frame, or no numbers?
  • GoatCounter only allows framing from allowlisted sites: add this site under Settings → Sites that can embed GoatCounter, then reload.
  • If the dashboard is not public, paste an access token (Settings → Dashboard viewable by → logged in users or with secret token).
  • Content blockers hide GoatCounter from some visitors, so real traffic is a little higher than what is shown here.
  • Locations are country and region — GoatCounter deliberately does not resolve cities.

Cookieless and no stored IP addresses: GoatCounter keeps a country, a region, a browser and a screen size, and nothing that identifies a person. Visits from localhost are never counted. The match_start event tells the people who played apart from the people who only looked.
